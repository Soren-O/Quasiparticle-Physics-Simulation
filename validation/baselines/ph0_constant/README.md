# Ph0-constant baselines

Frozen CSVs generated by paper-faithful reproduction scripts under
`validation/fischer_2023/` (Fischer 2023) and `validation/fischer_2024/`
(Fischer 2024). The workflow for each figure:

1. Run the reproduction module once:
   ```
   python -m validation.fischer_2023.fig3_paper
   ```
   It writes the CSV (this directory) and a companion PDF plot.

2. **Visually compare the PDF** against the published figure from the
   original paper (`Documentation/Current/*.pdf` in the reference tree).
   If the shape and amplitude match, the baseline is sound.

3. Commit the CSV. Subsequent `pytest -m slow` runs assert the new
   framework reproduces the pinned numbers to the tolerance declared in
   each regression test.

Tolerance choices per `New Framework Plan` §6.4.1:

| Figure                            | Tolerance | Why                                  |
|-----------------------------------|-----------|--------------------------------------|
| Fischer 2023 Fig 3 (paper grid)   | 1e-6      | Picard/coupled-Newton iteration tol  |
| Fischer 2023 Fig 5 (paper)        | 1e-6      | Iterative modes                      |
| Fischer 2023 Fig 7 (paper)        | 1e-4      | nbar loop + Mattis–Bardeen quadrature |
| Fischer 2023 Figs 9–13 (Q_i vs P) | 1e-4      | nbar loop + Mattis–Bardeen quadrature |
| Fischer 2024 Figs 5–8 pair-breaking photon | 1e-6      | Iterative                            |

These baselines are *regression* targets, not independent reference
truth — see `New Framework Plan` §7.5 for the discussion of why Gate 3
uses self-pinned baselines with manual visual verification instead of
externally-generated ones.
