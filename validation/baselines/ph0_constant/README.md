# Ph0-constant baselines

Frozen CSVs generated by paper-facing and paper-topology validation scripts under
`validation/fischer_2023/` (Fischer 2023) and `validation/fischer_2024/`
(Fischer 2024). Baselines are generated by repository validation modules or
their dedicated campaign drivers. Canonical multi-file evidence must be
staged, validated, and promoted as one matched set; do not overwrite a
canonical CSV or PDF independently. The workflow for each figure:

1. Run the reproduction module or its dedicated publisher:
   ```
   python -m validation.fischer_2023.fig3_paper
   ```
   Fig. 7 uses:
   ```
   python -m scripts.regenerate_fischer_fig7_parallel
   ```
   Publishers stage and validate their complete evidence before promotion.
   F24 promotes PDF then authenticating CSV. Fig. 3 promotes PDF and its
   validation record before the authenticating CSV. Fig. 7 promotes PDF,
   authenticating CSV, then the campaign attestation. In every case, readers
   reject an incomplete or mismatched set.

2. **Visually compare the PDF** against the published figure from the
   original paper (`Documentation/Current/*.pdf` in the reference tree).
   This is a manual sanity check, not physics or paper-parity certification.

3. Commit the complete matched evidence set: CSV, PDF, and any validation
   record or promotion attestation. Subsequent tests first reject stale or
   mismatched evidence, then assert the framework reproduces the pinned
   numbers to the tolerance declared in each regression test.
