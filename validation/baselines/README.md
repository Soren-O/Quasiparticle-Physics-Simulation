# Frozen parity baselines

Empty until Gate 3.5 (New Framework Plan §7.5). The baselines here are
generated by the *old* `Active Code/qpsim/` repository using the
Ph0-constant-τ_l phonon model — they exist to audit the new
framework's T3 backend against the current scientific output.

The Ph0-Kaplan *characterization* baselines (a separate set, not
comparable to the parity baselines) are generated later in *this* repo
once Ph0-Kaplan is implemented; they live under
`validation/baselines/ph0_kaplan/` once pinned.

See New Framework Plan §6.4.1 (parity) and §6.4.2 (characterization).
