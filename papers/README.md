# papers/

Manuscripts that live alongside the simulation code they cite.

## qp-diffusion/

The quasiparticle diffusion-operator manuscript (paper.tex ~50 pp +
supplement.tex ~48 pp, figures, sympy verify scripts). **This is the
live working copy** — imported 2026-07-02 from the private repo
`Soren-O/qp-diffusion-paper` at commit `6e2fa29`; that repo is now a
frozen history archive (its pre-import history stays there, and the
deeper pre-June-2026 history exists only on the Mac).

Notes:
- Read `qp-diffusion/CLAUDE.md` before reviewing — it holds the settled
  conventions/physics guards.
- The `verify_*.py` scripts are sympy proof-checks run via the
  Makefile (`make verify`), not part of the qpsim package; `papers/` is
  excluded from ruff and pytest.
- `supplement.pdf` is deliberately tracked; `paper.pdf` is rebuilt by
  latexmk and ignored.
- The paper's benchmark figures are generated by this repo's
  `validation/diffusion_operators/` module — that link is why the
  manuscript lives here.
