Step 1

Import the device, or state its extent.

The mask decides the dimensionality: a rectangle one cell wide is a 1-D strip and a single cell is 0-D, both solved by the same core. It also decides which terms exist — a single cell has no neighbours to diffuse to, so the next step will show the transport term greyed. Import the geometry to see it on the right, then click any edge to assign its boundary condition.
